- Reworked generated output into readable, titled sections with blank-line separation. Master, short, and platform outputs are editable textareas; manual platform edits persist until the user chooses Regenerate Output.

- Added Copy + Open Gemini for URL reverse-engineering prompts, retaining the no-API structured template workflow.
- Added a "Don't show this welcome tour again" preference and a seen-state so onboarding no longer reappears automatically after the first launch.
- Added Bandmate Edition copy for Rob and the A Separate Peace crew plus a polished README.
- Did not overwrite the supplied failing source.

## Browser/device evidence

The supplied real-device recording was inspected as the failure reference. It shows the previous shell trapping the user near the bottom of Home while the fixed navigation and dynamic content competed for scroll control.

The accepted cinematic target was inspected at native resolution and used as the visual reference for the rebuild.

Local browser automation could not be completed against the local artifact in this runtime: the supported browser rejects `file://` URLs and blocks the sandbox's localhost endpoint (`ERR_BLOCKED_BY_CLIENT`). The deployed HTTPS artifact is the browser QA target; physical iPhone/WebKit hardware remains the only environment-specific acceptance item that cannot be emulated exactly here.

## Final scroll model

`html/body` do not scroll. `.native-shell` is a flex column. `.native-main` is the flex-growing region with `min-height:0` and `overflow:hidden`. Only the active `.app-view` scrolls vertically with `-webkit-overflow-scrolling: touch`; the mobile tab bar is a normal flex item outside that scroll container, so the last control is not hidden beneath an overlay.
